# 5. 다국어 전환 체크리스트

[다국어 지원](./04-다국어-지원.md)에서 설명한 패턴(`useI18n().t()` / `apiError()`)으로 전체 앱을 옮기는 작업의 진행 상황이에요. 한 번에 다 하기엔 너무 커서(Vue 파일 43개, 한글 포함 줄 약 1,200줄) 화면 단위로 나눠서 세션마다 이어서 진행해요.

**우선순위 기준**: 커뮤니티 멤버가 매일 보는 화면 → 가끔 쓰는 화면 → 관리자 전용(운영자 본인만 보고, 이미 한국어 문서 보고 셀프호스트할 정도의 사람이라 제일 안 급함).

체크된 파일은 `app/i18n/{ko,ja,zh}.json`에 그 화면의 문자열이 다 들어가 있고, 관련 서버 API가 있다면 `apiError()`로 코드화까지 끝난 상태예요. 괄호 안 숫자는 한글이 포함된 줄 수 대략치(중복·코드와 섞인 줄 포함이라 실제 서로 다른 문자열 수보다 큼) — 작업량 감 잡는 용도예요.
