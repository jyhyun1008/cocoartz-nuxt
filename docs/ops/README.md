# 서버 운영 가이드

이 문서들은 [사용자 가이드](../README.md), [관리자 가이드](../admin/README.md)와 또 다른, **이 소프트웨어(코코아츠) 자체를 설치·배포·운영하는 사람** 입장의 가이드예요. 관리자 가이드가 "이미 떠 있는 서버의 웹 화면에서 뭘 할 수 있는지"를 다룬다면, 여기는 "서버를 어떻게 띄우고, 새 버전으로 어떻게 올리고, 어떻게 완전히 내리는지"를 다뤄요.

Docker/Docker Compose와 터미널 사용에 익숙하다는 걸 전제로 써요.

## 목차

1. [설치](./01-설치.md) — 처음 서버를 띄우기
2. [업데이트](./02-업데이트.md) — 새 버전으로 올리기, 마이그레이션
3. [삭제(서버 자체 종료)](./03-삭제.md) — 영구히 내릴 때(self-destruct)

## 큰 그림

컨테이너는 두 개예요 — `db`(Postgres)와 `app`(Nuxt/Nitro 서버, 웹소켓 포함). `app`은 `docker-entrypoint.sh`가 컨테이너 시작마다 자동으로 DB 마이그레이션을 먼저 돌린 뒤 서버를 띄워요. 별도의 큐/캐시 서버(Redis 등)는 없고, 전부 이 두 컨테이너 안에서 돌아가요 — 그래서 지금 구조로는 `app`을 여러 대로 늘리는(수평 확장) 게 안 되고, 한 대의 스펙을 올리는 방향(수직 확장)만 가능해요.
