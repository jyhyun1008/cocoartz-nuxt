# 6. 위키 채널

위키 채널은 커뮤니티가 다 같이 쓰고 고치는 문서 공간이에요. 나무위키/위키백과처럼 여러 페이지가 서로 링크로 연결돼요.

## 누가 쓸 수 있나요?

**로그인한 유저라면 누구나** 새 페이지를 만들거나 기존 페이지를 편집할 수 있어요. 특정 작성자만 고칠 수 있는 게 아니라 열려있는 구조예요. 로그인하지 않은 사람도 페이지를 읽는 건 가능해요.

## 페이지 만들기 / 편집하기

- 목록에서 **+ 새 페이지**를 누르면 제목과 본문을 입력하는 화면이 열려요. 게시판과 마찬가지로 **작성** / **미리보기** 탭을 오가며 마크다운 툴바(굵게/기울임/제목/목록/**링크**/이모지)를 쓸 수 있어요. 미리보기 탭에서는 아래에서 설명하는 `[[페이지 링크]]`까지 실제와 똑같이 렌더링돼서 확인할 수 있어요. 엔터로 줄바꿈 한 번만 해도 그대로 줄이 바뀌어서 보여요.
- 이모지 피커에 서버 커스텀 이모지가 있다면 **커스텀** 탭에서 골라 `:샷코드:` 형태로 넣을 수 있고, 실제로는 이미지로 보여요.
- 새로 쓸 때는 **페이지 생성**, 기존 페이지를 고칠 때는 **변경사항 저장** 버튼을 눌러요.

## 페이지 사이 링크 걸기

본문에 `[[페이지 이름]]`처럼 대괄호 두 개로 감싸서 쓰면, 그 부분이 자동으로 해당 이름의 위키 페이지로 가는 링크가 돼요. 아직 없는 페이지 이름을 링크로 걸어두고, 나중에 그 이름으로 새 페이지를 만드는 식으로 위키를 계속 확장해나갈 수 있어요.

링크로 보일 텍스트를 문서 이름과 다르게 쓰고 싶다면 `[[문서 이름|표시할 텍스트]]`처럼 파이프(`|`) 뒤에 원하는 문구를 적으면 돼요. 예를 들어 `[[설치 가이드|이곳을 참조해주세요]]`라고 쓰면 "이곳을 참조해주세요"라는 문구로 보이면서 실제로는 "설치 가이드" 페이지로 연결돼요.

## 공유하기

페이지 상세 화면 상단의 **공유** 아이콘을 누르면 그 페이지 링크가 클립보드에 복사돼요.

## 첫 화면(대문)

위키 채널에 처음 들어가면 자동으로 그 채널에서 **가장 먼저 만들어진 페이지**가 대문처럼 열려요.

## 이력(편집 기록)

페이지 상세 화면의 **이력** 버튼을 누르면 이전에 저장됐던 버전들을 볼 수 있어요. 각 이전 버전은 편집 시각과 그 당시의 제목·본문 일부(미리보기)를 보여줘요. 누가 언제 실수로 내용을 지워도 이전 버전을 참고해서 복구할 수 있어요.
