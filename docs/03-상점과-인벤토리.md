# 3. 상점과 인벤토리

재화(코인)로 캐릭터 파츠나 방 꾸미기용 아이템을 살 수 있는 **상점**과, 산 아이템을 확인·사용하는 **인벤토리**를 다뤄요.

## 상점 열기

화면 왼쪽 아래 내 프로필 카드의 잔액(코인) 표시나 상점 아이콘을 누르면 상점 창이 열려요. 위쪽 탭이 두 단계로 나뉘어요.

- **아바타 / 아이템** — 큰 분류예요.
  - **아바타**: 헤어 · 상의 · 하의 · 신발 · 얼굴 · 바디
  - **아이템**: 지형 · 맵 아이템 · 기능 아이템 · 소모품
- 그 아래 작은 탭이 실제 카테고리예요. 카테고리를 고르면 그 안에 등록된 아이템이 카드로 나열돼요.

## 구매하기

- **아바타 / 지형**은 "있다·없다"만 의미가 있어서 한 번에 1개만 사요. 이미 가지고 있으면 카드에 **보유중** 표시가 뜨고 다시 살 수 없어요.
- **맵 아이템 / 기능 아이템 / 소모품**은 여러 개 쌓아둘 수 있는 아이템이라, 카드에서 수량을 고른 뒤 구매해요(이미 갖고 있어도 더 살 수 있어요).

구매 버튼을 누르면 잔액에서 가격만큼 바로 차감되고, 잔액이 모자라면 실패 메시지가 떠요. 구매 즉시 인벤토리에 들어가고, 사이드바/프로필의 잔액 표시도 같이 갱신돼요.

## 인벤토리 확인하기

내 프로필 페이지(`/@내핸들`)에 **인벤토리** 섹션이 있어요(본인 프로필에서만 보여요). 상점과 같은 카테고리 구성으로 지금까지 산 아이템이 나열되고, 여러 개 살 수 있는 아이템은 보유 개수가 같이 표시돼요.

## 아바타 파츠 장착하기

인벤토리에서 보유한 아바타 아이템(헤어/상의/하의/신발/얼굴/바디) 카드를 누르면 **바로 장착**돼요 — 별도의 "장착" 화면 없이 인벤토리가 곧 장착 화면이에요. 지금 장착 중인 파츠는 카드 테두리가 서버 테마색(악센트 컬러)으로 강조되고 **장착 중** 표시가 붙어요. 장착한 모습은 [마을 맵 위 캐릭터](./02-마을과-캐릭터.md#캐릭터-모습)와 다른 유저 화면에도 실시간으로 반영돼요.

가입하면 기본 헤어/상의/하의/신발/얼굴/바디 세트를 자동으로 보유한 상태로 시작해서, 아무것도 안 사도 캐릭터가 벌거벗지는 않아요.

## 지형 · 맵 아이템은 방 꾸미기에서 씀

지형(바닥 타일)과 맵 아이템(장식 오브젝트)은 상점/인벤토리에서 "보유"만 하고, 실제로 맵에 배치하는 건 [프로필과 내 방 꾸미기](./04-프로필과-내방.md#내-방-꾸미기)의 편집기에서 해요 — 편집기 팔레트에는 내가 보유한 만큼만 골라 쓸 수 있게 나와요.

기본 지형(잔디/물/모래/돌/나무 등)은 가입하면 자동으로 보유하지만, 서버에 따라 관리자가 등록해둔 특수 지형이나 맵 아이템은 상점에서 따로 사야 배치할 수 있어요.
