# 5. 채팅 채널

## 기본 채팅

채팅 채널에 들어가면 맵 위에 채팅창이 뜨고, 같은 채널에 있는 유저들과 실시간으로 대화할 수 있어요.

- **엔터**로 메시지 전송, **Shift+엔터**로 줄바꿈만 하고 전송은 안 해요. (한글 입력 중 조합 상태에서 엔터를 눌러도 실수로 전송되지 않도록 처리되어 있어요)
- 메시지에는 **마크다운**이 지원돼요 — `**굵게**`, `*기울임*`, 링크 등을 쓸 수 있고, 줄바꿈도 그대로 반영돼요.
- 입력창 옆 스마일 아이콘을 누르면 **이모지 피커**가 열려서 유니코드 이모지를 골라 넣을 수 있어요. 서버에 등록된 커스텀 이모지가 있다면 피커 상단의 **커스텀** 탭에서 골라 넣을 수도 있어요 — `:샷코드:` 형태로 삽입되고 메시지에는 실제 이미지로 보여요.
- 채팅창은 화면 아래쪽의 작은 창(기본) ↔ 화면 중앙의 큰 창, 두 크기로 전환할 수 있어요 (대각선 화살표 아이콘). 닫으면 "채팅 열기" 버튼이 남아서 다시 열 수 있어요.

## 채팅 리액션

각 채팅 메시지 아래에 이모지 리액션을 달 수 있어요. 메시지 아래의 **+** 버튼을 누르면 이모지 피커가 뜨고, 고른 이모지가 리액션으로 붙어요. 이미 달린 리액션을 다시 누르면 취소돼요. 같은 이모지에 여러 명이 반응하면 숫자로 표시돼요. 유니코드 이모지뿐 아니라 서버의 커스텀 이모지도 리액션으로 달 수 있어요.

## 내가 보낸 메시지 수정/삭제

내가 쓴 메시지 옆에는 연필(수정)과 휴지통(삭제) 아이콘이 떠요.

- **수정**하면 메시지 내용이 바로 바뀌고, 다른 사람 화면에도 실시간으로 반영돼요. 수정된 메시지에는 **(수정됨)** 표시가 붙어서 원문이 아니라는 걸 알 수 있어요.
- **삭제**는 확인창 없이 바로 지워져요 (가벼운 채팅 메시지라 되돌릴 필요까지는 없다고 판단했어요). 삭제하면 다른 사람 화면에서도 즉시 사라져요.

다른 사람이 쓴 메시지는 수정/삭제 대신 **뮤트** 아이콘이 떠요 — 그 사람을 소프트/하드 뮤트하면 내 화면에서 그 사람 메시지가 걸러져요. 자세한 건 [프로필과 내 방 꾸미기](./04-프로필과-내방.md#다른-사람-뮤트하기) 문서를 참고하세요.

## 음성 채팅방 (TTS)

일반 채팅과 별개로, **음성 채팅방**이라는 특수한 채널이 있어요. 여기서는 누가 메시지를 보내면 브라우저가 **그 사람 이름과 메시지 내용을 실제 음성으로 읽어줘요** (텍스트를 목소리로 바꿔주는 TTS 기능). 헤더에 "TTS" 배지가 있고, 메시지가 재생 중일 때는 "읽는 중" 표시로 바뀌어요.

- 입력창 placeholder에도 안내가 나와요: "메시지 입력 (전송 시 읽어줍니다)"
- 목소리/속도 등을 따로 설정하는 기능은 없고, 사용 중인 기기(브라우저)의 기본 한국어 음성으로 자동 재생돼요.
- 조용한 공간이 아니라면 소리가 날 수 있으니 참고하세요. 창을 닫으면 재생 중이던 음성도 멈춰요.
- 음성 채팅방에는 이모지 피커나 리액션 기능은 없고, 순수하게 텍스트를 주고받고 들려주는 용도예요. 다만 메시지 수정/삭제와 다른 사람 뮤트는 일반 채팅과 똑같이 지원돼요.
