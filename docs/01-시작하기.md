# 1. 시작하기

## 회원가입

로그인 화면에서 **회원가입** 탭을 누르면 아래 정보를 입력해요.

- **핸들** *(변경할 수 없습니다)* — 영문/숫자로 된 나만의 고유 아이디예요. 한 번 정하면 나중에 바꿀 수 없으니 신중하게 골라주세요. (화면에 보이는 표시 이름인 "닉네임"은 가입 후 프로필에서 언제든 바꿀 수 있어요 — [프로필과 내 방 꾸미기](./04-프로필과-내방.md) 참고)
- **이메일**
- **비밀번호** — 6자 이상

다 입력하고 **가입하기**를 누르면 완료됩니다.

가입이 완료되면(승인제 서버라면 승인된 뒤) 재화가 자동으로 조금 들어와 있어요 — 서버가 정해둔 "가입 보너스"예요(기본값 100 코코아, 서버마다 금액이 다르거나 아예 없을 수도 있어요). 재화에 대한 자세한 내용은 [마을과 캐릭터](./02-마을과-캐릭터.md#재화코인-모으기) 문서를 참고하세요.

## 가입 후 바로 로그인이 안 될 수도 있어요

서버 설정에 따라 가입 절차가 다를 수 있어요.

- **자유 가입**인 서버라면 가입 즉시 자동으로 로그인돼요.
- **승인제**인 서버라면 가입 신청까지만 접수되고, 화면에 "가입 신청이 완료되었습니다. 관리자 승인 후 로그인할 수 있어요." 라는 메시지가 떠요. 이 경우 관리자가 승인해줄 때까지 기다렸다가 로그인 탭에서 다시 로그인을 시도하면 됩니다. 승인 전에 로그인을 시도하면 "관리자 승인 대기 중인 계정입니다"라는 안내가 나와요.
- 서버가 **가입을 막아둔 상태**라면 "현재 신규 가입이 제한되어 있습니다"라는 메시지가 뜹니다. 이럴 땐 서버 관리자에게 직접 문의해보세요.

## 로그인

**로그인** 탭에서 이메일 + 비밀번호를 입력하고 로그인하면, 서버의 기본 화면(마을)으로 이동해요.

## 로그인 후 첫 화면

로그인하면 바로 **마을** 맵에 캐릭터가 서 있는 화면이 나와요. 왼쪽 사이드바에서 다른 채널로 이동할 수 있고, 화면 오른쪽 아래(또는 하단)의 프로필 영역에서 내 프로필로 갈 수 있어요.
