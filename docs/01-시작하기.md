# 1. 시작하기

## 회원가입

로그인 화면에서 **회원가입** 탭을 누르면 아래 정보를 입력해요.

- **핸들** *(변경할 수 없습니다)* — 영문/숫자로 된 나만의 고유 아이디예요. 한 번 정하면 나중에 바꿀 수 없으니 신중하게 골라주세요. (화면에 보이는 표시 이름인 "닉네임"은 가입 후 프로필에서 언제든 바꿀 수 있어요 — [프로필과 내 방 꾸미기](./04-프로필과-내방.md) 참고)
- **이메일**
- **비밀번호** — 6자 이상

다 입력하고 **가입하기**를 누르면 완료됩니다.

가입이 완료되면(승인제 서버라면 승인된 뒤) 재화가 자동으로 조금 들어와 있어요 — 서버가 정해둔 "가입 보너스"예요(기본값 100 코코아, 서버마다 금액이 다르거나 아예 없을 수도 있어요). 재화에 대한 자세한 내용은 [마을과 캐릭터](./02-마을과-캐릭터.md#재화코인-모으기) 문서를 참고하세요.

## 가입 후 바로 로그인이 안 될 수도 있어요

서버 설정에 따라 가입 절차가 다를 수 있어요.

- **자유 가입**인 서버라면 가입 즉시 자동으로 로그인돼요 — 단, 서버가 이메일 인증을 요구하는 상태라면 자유 가입이어도 [이메일 인증](#이메일-인증-서버에-따라)을 마쳐야 로그인이 가능해요.
- **승인제**인 서버라면 가입 신청까지만 접수되고, 화면에 "가입 신청이 완료되었습니다. 관리자 승인 후 로그인할 수 있어요." 라는 메시지가 떠요. 이 경우 관리자가 승인해줄 때까지 기다렸다가 로그인 탭에서 다시 로그인을 시도하면 됩니다. 승인 전에 로그인을 시도하면 "관리자 승인 대기 중인 계정입니다"라는 안내가 나와요.
- 서버가 **가입을 막아둔 상태**라면 "현재 신규 가입이 제한되어 있습니다"라는 메시지가 뜹니다. 이럴 땐 서버 관리자에게 직접 문의해보세요.

## 로그인

**로그인** 탭에서 이메일 + 비밀번호를 입력하고 로그인하면, 서버의 기본 화면(마을)으로 이동해요.

**비밀번호를 잊어버렸다면** 로그인 탭의 "비밀번호를 잊으셨나요?" 링크를 눌러 가입한 이메일을 입력하세요. 그 이메일로 재설정 링크가 가고(1시간 동안 유효), 링크를 열어 새 비밀번호를 정하면 다시 로그인할 수 있어요. 서버가 이메일 발송 기능을 꺼둔 상태라면 이 방법을 쓸 수 없으니 관리자에게 직접 문의해야 해요.

## 로그인 후 첫 화면

로그인하면 바로 **마을** 맵에 캐릭터가 서 있는 화면이 나와요. 왼쪽 사이드바에서 다른 채널로 이동할 수 있고, 화면 오른쪽 아래(또는 하단)의 프로필 영역에서 내 프로필로 갈 수 있어요.

## 이메일 인증 (서버에 따라)

서버가 이메일 발송 기능을 켜둔 경우, 가입하면 인증 메일이 한 통 가고 **인증을 마쳐야 로그인할 수 있어요.** 가입 직후엔 "가입이 완료되었습니다. 메일함에서 인증 링크를 눌러야 로그인할 수 있어요."라는 안내만 뜨고, 인증 전에 로그인을 시도하면 "이메일 인증이 필요합니다"라는 메시지와 함께 **인증 메일 재전송** 버튼이 같이 떠요(로그인 없이도 누를 수 있어요). 이 기능이 서버에 생기기 전부터 있던 계정은 새로 인증할 필요 없이 그대로 로그인돼요.

인증 후에는 [연합 게시판](./09-연합-페디버스.md)처럼 내 활동이 다른 서버로 실제로 나가는 기능(연합 게시판 글쓰기/답글, 원격 계정 좋아요·팔로우 등)도 자유롭게 쓸 수 있어요. 이메일 발송 자체가 꺼져 있는 서버라면 이 인증 과정이 아예 없어요.

## 회원 탈퇴

[설정 페이지](./08-타임라인-설정-알림.md#설정-개인-설정) 맨 아래 "탈퇴하기" 버튼으로 언제든 탈퇴할 수 있어요. 비밀번호를 한 번 더 입력해서 확인하며, **되돌릴 수 없어요.** 탈퇴하면 로그인이 영구히 막히고, 그동안 쓴 글/댓글/채팅은 "탈퇴한 유저가 작성한 게시물입니다"로 바뀌어요(그 글에 달린 답글은 그대로 남아요). 연합된 다른 서버에도 계정이 삭제됐다고 알려서, 다른 서버에 남아있던 내 글도 정리돼요.
