# 코코아츠(CocoArtz) 사용 가이드

코코아츠는 아이소메트릭 맵 위에서 캐릭터가 돌아다니는, 디스코드와 비슷한 커뮤니티 공간이에요. 이 문서들은 **서버를 이용하는 일반 유저** 입장에서 어떤 기능이 있고 어떻게 쓰는지 정리한 가이드입니다. (서버 관리자용 설정 가이드는 아니에요!)

## 목차

1. [시작하기](./01-시작하기.md) — 가입, 로그인, 승인 절차
2. [마을과 캐릭터](./02-마을과-캐릭터.md) — 맵 이동, 확대/축소, 말풍선
3. [상점과 인벤토리](./03-상점과-인벤토리.md) — 아바타 파츠·아이템 구매, 장착, 인벤토리
4. [프로필과 내 방 꾸미기](./04-프로필과-내방.md) — 프로필 사진/배너/소개, 개인 방 편집, 농사
5. [채팅 채널](./05-채팅.md) — 일반 채팅, 리액션, 음성(TTS) 채팅방
6. [게시판 채널](./06-게시판.md) — 글쓰기, 좋아요, 댓글, 리액션
7. [위키 채널](./07-위키.md) — 페이지 작성, 링크, 이력
8. [타임라인 · 설정 · 알림](./08-타임라인-설정-알림.md) — 팔로우 피드, 출석체크, 테마, 이메일 인증, 알림
9. [연합(페디버스) 기능](./09-연합-페디버스.md) — 외부의 마스토돈/미스키 서버와 연결하기

> 서버를 운영하는 관리자라면 [관리자 가이드](./admin/README.md)를 참고하세요.
> 서버를 직접 설치·배포하는 입장이라면 [서버 운영 가이드](./ops/README.md)를 참고하세요.

## 서버 구조 한눈에 보기

코코아츠 서버 하나에는 여러 개의 **채널**이 있고, 각 채널은 성격에 따라 몇 가지 종류로 나뉘어요.

| 채널 종류 | 하는 일 |
|---|---|
| 🏠 마을 | 캐릭터가 돌아다니는 기본 맵. 로그인하면 항상 여기서 시작해요 |
| 📢 게시판 | 글/사진을 올리고 댓글·좋아요·리액션을 남기는 공간 |
| 💬 채팅방 | 실시간 텍스트 채팅 (맵 위 다른 유저와 같이) |
| 🔊 음성 채팅방 | 채팅 내용을 TTS(음성)로 읽어주는 채팅방 |
| 📖 위키 | 다 같이 쓰고 고칠 수 있는 문서 채널 |

채널 목록은 화면 왼쪽 사이드바에 있고, 그 위에는 **타임라인**(내가 팔로우한 사람들의 글 모아보기)으로 가는 링크가 항상 고정되어 있어요.

각 서버의 정확한 채널 이름·구성은 서버마다 다를 수 있어요 (관리자가 자유롭게 채널을 만들고 이름 붙일 수 있거든요). 이 가이드에서는 채널 "종류"별 공통 사용법을 설명합니다.

화면 상단에는 채널과 별개로 **서버 정보** / **멤버** / **알림** 아이콘이 항상 떠 있어요.

- **서버 정보** — 서버 이름·아이콘, 소개글, 개설일, 가입 방식, 채널 개수를 한눈에 볼 수 있어요.
- **멤버** — 이 서버에 가입된 유저 목록이에요. 관리자는 이름 옆에 "관리자" 배지가 붙어서 구분돼요.
- **알림**은 [8번 문서](./08-타임라인-설정-알림.md)에서 다뤄요.
