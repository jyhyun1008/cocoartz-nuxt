# 3. 채널 관리

"채널 목록" 탭에서 서버의 채널(마을 제외 — 마을/공지 게시판은 [기본 페이지](#기본-페이지-마을--공지-게시판)에서 따로 관리) 구성을 관리해요.

## 채널 만들기 / 편집

**+ 새 채널** 버튼(또는 기존 채널의 연필 아이콘)을 누르면 아래 항목을 입력해요.

| 항목 | 설명 |
|---|---|
| 채널 이름 | 사이드바에 보일 이름 |
| URL 경로 | `/free`처럼 슬래시로 시작하는 고유 경로 |
| 채널 유형 | 💬 채팅방(room) · 📋 게시판(board) · 🔊 음성채팅방(voice) · 📖 위키(wiki) |
| 채널 소개 | 선택 사항 |

채널 유형이 **게시판**일 때만 **"연합 게시판으로 지정"** 체크박스가 나와요 — 서버당 1개만 지정할 수 있고, 이미 다른 게시판이 연합으로 지정돼 있었다면 체크하는 순간 그쪽은 자동 해제돼요. 연합 게시판이 뭔지, 켜면 어떻게 되는지는 [연합(페디버스) 기능](../09-연합-페디버스.md) 문서를 참고하세요.

편집 화면에서는 이름/경로/유형/소개/연합 지정 외에 **맵 편집** 버튼으로 그 채널(채팅방/게시판 등 종류 무관)의 맵을 바로 편집할 수 있어요.

## 순서 바꾸기 / 섹션 제목

각 채널 항목의 **↑ / ↓** 버튼으로 사이드바에 보이는 순서를 바꿀 수 있어요. **제목 추가** 입력창에 텍스트를 넣고 "제목 추가"를 누르면 채널이 아닌 순수 구분선(섹션 제목)을 목록 중간에 끼워넣을 수 있어요 — 이것도 같이 위/아래로 옮기거나 삭제할 수 있어요.

바꾼 뒤에는 **순서 저장**을 눌러야 반영돼요.

## 채널 삭제

휴지통 아이콘을 누르면 확인창이 떠요. 삭제해도 그 채널에 있던 메시지/게시물 자체는 DB에 남아있고, 단지 채널 목록(사이드바)에서만 사라져요.

## 기본 페이지(마을 / 공지 게시판)

사이드바에 항상 고정되어 있는 "마을"과 "공지 게시판"은 위 채널 목록과 별개로 관리해요("기본 페이지" 탭). 이름을 바꾸고 **이름 저장**을 누르거나, **맵 편집** 버튼으로 두 페이지의 맵을 편집할 수 있어요. 별도 채널로 새로 만들 필요 없이 여기서 바로 처리돼요.
