# 4. 이모지 · 이메일 설정

## 커스텀 이모지

"커스텀 이모지" 탭에서 이 서버만의 이모지를 등록해요. 등록된 이모지는 게시판/채팅/위키 본문과 리액션에서 `:샷코드:` 형태로 쓸 수 있고, [연합 게시판](../09-연합-페디버스.md)에 올라간 글에 쓰였다면 다른 페디버스 서버(마스토돈 등)에서도 이미지로 정상 표시돼요.

새 이모지를 추가하려면 **오브젝트 스토리지**가 설정돼 있어야 해요(이 서버의 배포 설정에 달려있고, 설정 안 됐으면 탭에 안내 문구만 뜨고 업로드 버튼이 비활성화돼요). 설정돼 있다면:

1. 샷코드(영문 소문자/숫자/밑줄, 콜론 없이)를 입력해요.
2. 이미지 파일(png/jpeg/webp/gif)을 업로드해요.

등록된 이모지는 목록에서 휴지통 아이콘으로 삭제할 수 있어요. 삭제하면 이미 쓰인 글에서는 더 이상 이미지로 안 보여요.

## 이메일(SMTP) 설정

"이메일" 탭은 **승인제 가입** 서버에서 특히 중요해요 — 새 가입 신청이 들어오면 관리자에게, 승인 처리되면 신청자 본인에게 자동으로 메일을 보내줘요.

| 항목 | 설명 |
|---|---|
| SMTP 호스트/포트 | 메일 발송에 쓸 SMTP 서버 주소·포트 (예: 587) |
| TLS(465) 사용 | 465 포트처럼 처음부터 TLS로 접속하는 방식이면 체크 |
| 계정 / 비밀번호 | SMTP 로그인 정보. 비밀번호는 한 번 설정하면 화면에 다시 안 보이고, 바꿀 때만 새로 입력하면 돼요 |
| 발신 이름 / 발신 주소 | 선택 사항. 비워두면 계정 정보를 그대로 써요 |
| 이메일 발송 사용 | 이 체크가 꺼져 있으면 나머지 값을 다 채워도 실제로 메일이 나가지 않아요 |

저장 후 **테스트 메일 보내기**로 실제 발송이 되는지 바로 확인해볼 수 있어요.

> ⚠️ **"이메일 발송 사용"을 켜두면 이메일 인증도 같이 요구되기 시작해요.** 별도의 온/오프 스위치가 없고, 이 체크 하나로 결정돼요 — 켜두면 이 시점 이후 새로 가입하는 유저에게 인증 메일이 나가고, **인증을 마치지 않으면 로그인 자체가 막혀요**(관리자 계정은 예외 — 메일 문제로 관리자가 자기 서버에서 로그아웃되는 사고를 막기 위함). 이 기능이 생기기 전에 이미 가입해 있던 유저는 전부 소급 인증 처리돼서 갑자기 로그인이 막히지 않아요. 이 체크를 꺼두면 인증 자체가 요구되지 않고, 기존 유저의 로그인도 영향 없어요.
>
> 이메일이 꺼져 있으면(또는 SMTP 정보가 덜 채워져 있으면) [서버 정보 탭](./01-서버-정보.md#가입-방식)에서 "자유 가입"/"승인제 가입"을 아예 고를 수 없어요 — 가입을 열 거면 이메일 설정을 먼저 끝내야 해요.
>
> 비밀번호를 잊은 유저를 위한 **비밀번호 재설정 메일**도 이 SMTP 설정을 그대로 씀 — 여기가 꺼져 있으면 로그인 화면의 "비밀번호를 잊으셨나요?" 링크로 요청해도 메일이 안 나가요(단, 화면엔 계정 존재 여부를 숨기려고 성공한 것처럼 그대로 뜸).
