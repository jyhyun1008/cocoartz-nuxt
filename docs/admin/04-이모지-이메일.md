# 4. 이모지 · 이메일 설정

## 커스텀 이모지

"커스텀 이모지" 탭에서 이 서버만의 이모지를 등록해요. 등록된 이모지는 게시판/채팅/위키 본문과 리액션에서 `:샷코드:` 형태로 쓸 수 있고, [연합 게시판](../08-연합-페디버스.md)에 올라간 글에 쓰였다면 다른 페디버스 서버(마스토돈 등)에서도 이미지로 정상 표시돼요.

새 이모지를 추가하려면 **오브젝트 스토리지**가 설정돼 있어야 해요(이 서버의 배포 설정에 달려있고, 설정 안 됐으면 탭에 안내 문구만 뜨고 업로드 버튼이 비활성화돼요). 설정돼 있다면:

1. 샷코드(영문 소문자/숫자/밑줄, 콜론 없이)를 입력해요.
2. 이미지 파일(png/jpeg/webp/gif)을 업로드해요.

등록된 이모지는 목록에서 휴지통 아이콘으로 삭제할 수 있어요. 삭제하면 이미 쓰인 글에서는 더 이상 이미지로 안 보여요.

## 이메일(SMTP) 설정

"이메일" 탭은 **승인제 가입** 서버에서 특히 중요해요 — 새 가입 신청이 들어오면 관리자에게, 승인 처리되면 신청자 본인에게 자동으로 메일을 보내줘요.

| 항목 | 설명 |
|---|---|
| SMTP 호스트/포트 | 메일 발송에 쓸 SMTP 서버 주소·포트 (예: 587) |
| TLS(465) 사용 | 465 포트처럼 처음부터 TLS로 접속하는 방식이면 체크 |
| 계정 / 비밀번호 | SMTP 로그인 정보. 비밀번호는 한 번 설정하면 화면에 다시 안 보이고, 바꿀 때만 새로 입력하면 돼요 |
| 발신 이름 / 발신 주소 | 선택 사항. 비워두면 계정 정보를 그대로 써요 |
| 이메일 발송 사용 | 이 체크가 꺼져 있으면 나머지 값을 다 채워도 실제로 메일이 나가지 않아요 |

저장 후 **테스트 메일 보내기**로 실제 발송이 되는지 바로 확인해볼 수 있어요.
