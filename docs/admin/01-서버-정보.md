# 1. 서버 정보

"서버 정보" 탭에서 서버 전체에 적용되는 기본값을 관리해요.

| 항목 | 설명 |
|---|---|
| 서버 이름 | 사이드바 상단 등에 표시되는 서버 이름 |
| 악센트 컬러 | 서버 전체 UI에 쓰이는 강조색. 색상 피커 또는 직접 `#RRGGBB` 입력 |
| 재화 이름 | 맵 아이템에서 얻는 코인 등에 붙는 이름(기본값 "코코아") — 서버 성격에 맞게 자유롭게 바꿀 수 있어요 |
| 가입 보너스 | 신규 가입 시 자동으로 지급할 재화 양(기본값 100). **0으로 두면 보너스를 지급하지 않아요** |
| 서버 소개 | 선택 사항. [서버 정보 화면](../README.md)에 보여지는 소개글 |
| 서버 아이콘 | 이미지 URL을 직접 입력하거나, 오브젝트 스토리지가 설정되어 있으면 파일 업로드 가능 |
| 가입 방식 | 아래 참고 |

값을 바꾼 뒤에는 **서버 정보 저장** 버튼을 꼭 눌러야 반영돼요.

## 가입 방식

- **자유 가입** — 누구나 가입하면 즉시 로그인돼요.
- **승인제 가입** — 가입 신청만 접수되고, 관리자가 [멤버 관리 탭](./02-멤버-관리.md#가입-승인)에서 승인해야 로그인할 수 있어요. 이메일 설정이 켜져 있다면 새 신청이 들어올 때마다 관리자에게 메일로도 알려줘요(자세한 건 [이모지 · 이메일 설정](./04-이모지-이메일.md) 참고).
- **가입 차단** — 신규 가입 자체를 막아요.

## 재화 이름 / 가입 보너스는 어디서 쓰이나요?

유저가 맵 위 아이템을 지나가며 코인을 모으는 기능([마을과 캐릭터](../02-마을과-캐릭터.md#재화코인-모으기) 참고)과, 가입 직후 자동 지급되는 보너스([시작하기](../01-시작하기.md) 참고)에 이 두 값이 그대로 쓰여요. 재화 이름을 바꾸면 프로필 카드의 잔액 표시 등에도 바로 반영돼요.
