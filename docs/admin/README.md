# 코코아츠(CocoArtz) 관리자 가이드

이 문서들은 [사용자 가이드](../README.md)와 별개로, **서버를 운영하는 관리자** 입장에서 필요한 설정과 관리 기능을 정리한 가이드예요. 일반 유저 기능은 다루지 않으니, 먼저 [사용자 가이드](../README.md)를 한 번 훑어보는 걸 추천해요. (서버 자체를 설치/배포/삭제하는 방법은 [서버 운영 가이드](../ops/README.md)에 따로 있어요 — 이 문서는 이미 떠 있는 서버의 웹 화면에서 할 수 있는 것들만 다뤄요.)

## 관리자 권한은 어떻게 생기나요?

이 서버에 **가장 먼저 가입한 계정**이 자동으로 전체 관리자(`isAdmin`)가 돼요. 그 이후 다른 계정에 전체 관리자 권한을 통째로 넘겨주는 화면은 아직 없어서, 꼭 필요하다면 DB에서 직접 `users.isAdmin`을 바꿔야 해요. 관리자 계정은 멤버 목록 등 여러 화면에서 이름 옆에 "관리자" 배지로 표시돼요.

전체 관리자를 만들지 않고도 [글 모더레이션 · 공지 글쓰기 · 유저 정지 · 관리자 설정 접근 같은 권한을 하나씩 따로 나눠줄 수 있어요](./02-멤버-관리.md#세부-권한-부여) — 예를 들어 신뢰하는 멤버에게 "유저 정지" 권한만 주는 식으로, DB를 직접 건드리지 않고도 필요한 만큼만 위임할 수 있어요.

## 관리자 화면 들어가기

관리자로 로그인한 상태면 화면 어딘가(사이드바 하단 또는 서버 정보 영역)의 **설정(톱니바퀴)** 아이콘을 눌러 "서버 설정 / 채널 관리" 창을 열 수 있어요. 이 창은 위쪽 탭으로 구역이 나뉘어 있어요.
