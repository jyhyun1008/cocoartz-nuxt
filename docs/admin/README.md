# 코코아츠(CocoArtz) 관리자 가이드

이 문서들은 [사용자 가이드](../README.md)와 별개로, **서버를 운영하는 관리자** 입장에서 필요한 설정과 관리 기능을 정리한 가이드예요. 일반 유저 기능은 다루지 않으니, 먼저 [사용자 가이드](../README.md)를 한 번 훑어보는 걸 추천해요.

## 관리자 권한은 어떻게 생기나요?

이 서버에 **가장 먼저 가입한 계정**이 자동으로 관리자가 돼요. 그 이후 다른 계정에 관리자 권한을 넘겨주는 화면은 아직 없어서, 필요하다면 DB에서 직접 `users.isAdmin`을 바꿔야 해요. 관리자 계정은 멤버 목록 등 여러 화면에서 이름 옆에 "관리자" 배지로 표시돼요.

## 관리자 화면 들어가기

관리자로 로그인한 상태면 화면 어딘가(사이드바 하단 또는 서버 정보 영역)의 **설정(톱니바퀴)** 아이콘을 눌러 "서버 설정 / 채널 관리" 창을 열 수 있어요. 이 창은 위쪽 탭으로 구역이 나뉘어 있어요.

## 목차

1. [서버 정보](./01-서버-정보.md) — 서버 이름·테마색, 재화 이름/가입 보너스, 가입 방식
2. [멤버 관리](./02-멤버-관리.md) — 가입 승인, 재화 지급, 정지/영구정지
3. [채널 관리](./03-채널-관리.md) — 채널 생성/편집/순서, 연합 게시판 지정, 기본 페이지 맵 편집
4. [이모지 · 이메일 설정](./04-이모지-이메일.md) — 커스텀 이모지, 가입 승인 알림 메일(SMTP)
