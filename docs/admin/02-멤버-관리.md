# 2. 멤버 관리

"멤버 관리" 탭(과 승인제 서버라면 그 옆 "가입 승인" 탭)에서 이 서버에 가입한 유저들을 관리해요.

## 가입 승인

가입 방식이 **승인제**일 때만 "가입 승인" 탭이 보여요. 승인 대기 중인 신청이 아바타/이름/이메일과 함께 목록에 뜨고, 각 항목마다:

- **✓ (승인)** — 승인하면 그 계정이 정식으로 로그인할 수 있게 돼요.
- **✕ (거절)** — 거절하면 신청이 목록에서 사라져요.

이메일 설정이 켜져 있다면 승인 시 신청자 본인에게도 안내 메일이 가요.

## 멤버 관리 탭

승인 여부와 무관하게 **가입된 모든 멤버**가 목록에 떠요. 검색창에 이름/아이디 일부를 입력해 좁혀볼 수 있고, 각 행의 **관리** 아이콘을 누르면 아래 액션 패널이 펼쳐져요.

### 재화 지급

숫자를 입력하고 **지급**을 누르면 그 멤버의 잔액에 즉시 더해져요. **마이너스 값을 넣으면 차감**도 가능해요(예: 오지급 정정). 재화 이름은 [서버 정보](./01-서버-정보.md)에서 설정한 이름을 그대로 따라요.

### 정지 / 영구정지

정상 상태인 멤버에게는:

- **정지** — 기간(1시간/1일/3일/7일 중 선택)과 사유(선택)를 입력하고 누르면, 그 기간 동안 로그인이 막혀요. 기간이 지나면 별도 해제 없이 **자동으로 다시 로그인 가능**해져요.
- **영구정지** — 확인 모달이 뜨고(사유 입력 가능), 확정하면 관리자가 직접 "영구정지 해제"를 누르기 전까지 로그인이 막혀요.

이미 정지/영구정지된 멤버는 목록에 상태 배지(예: "OO까지 정지", "영구정지됨")가 뜨고, 버튼이 **정지 해제** / **영구정지 해제**로 바뀌어요. 둘 다 걸려 있던 경우 영구정지가 우선이라 정지 정보는 자동으로 같이 지워져요.

> ⚠️ **정지·영구정지는 그 자리에서 바로 적용돼요.** 로그인 시도 자체가 막히는 것뿐 아니라, 그 멤버가 **이미 접속해서 맵을 돌아다니거나 채팅 중이었어도 그 순간 즉시 연결이 끊겨요.** 되돌릴 수 없는 조치는 아니지만(해제하면 다시 쓸 수 있음), 실제 이용을 막는 조치이니 신중하게 사용하세요.
