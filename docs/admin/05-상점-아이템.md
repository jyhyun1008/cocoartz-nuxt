# 5. 상점 아이템 관리

"상점 아이템" 탭에서 [상점](../03-상점과-인벤토리.md)에 진열할 아바타 파츠 · 지형 · 맵 아이템 · 맵 배경 · 기능 아이템 · 소모품을 관리자가 직접 등록/수정/삭제할 수 있어요. 코드를 손대지 않고도 새 아이템을 계속 추가할 수 있게 만들어둔 화면이에요.

## 카테고리

| 카테고리 | itemKey | 이미지 |
|---|---|---|
| 아바타(헤어/상의/하의/신발/얼굴/바디/한벌옷) | 캐릭터 파츠 variant 번호 | 768×1024 스프라이트시트 업로드 또는 관례 경로 |
| 아바타(데코) | 캐릭터 파츠 variant 번호 | 768×1424 전용 스프라이트시트 — [아래 참고](#데코-아이템-등록하기) |
| 지형 | 자유 번호(겹치면 등록 막힘) | 이미지 1장 업로드 — 그대로 실제 타일 그림으로 쓰임 |
| 맵 아이템 | 등록 시 자동 지정(직접 못 정함) | 레이어 6장 업로드(스프라이트 스태킹) |
| 맵 배경 | 자유 번호 | 이미지 1장 업로드 — 방 전체의 뒷배경으로 그대로 쓰임 |
| 기능 아이템(작물 포함) / 소모품 | 자유 문자열 | 아이콘 1장(선택) — 작물은 레이어 6장, [아래 참고](#작물-등록하기) |

아바타/지형/맵 배경은 상점·인벤토리에서 "있다/없다"만 의미가 있는 카테고리라 한 유저가 여러 개 못 쌓아요. 맵 아이템/기능 아이템/소모품은 여러 개 살 수 있는 카테고리예요. 자세한 유저 쪽 동작은 [상점과 인벤토리](../03-상점과-인벤토리.md) 문서를 참고하세요.

## 새 아이템 등록

목록 아래 **새 아이템 추가** 폼에서 카테고리 → (필요하면) itemKey → 이름/설명/가격을 입력하고, **등록하자마자 판매**(비활성으로 등록해서 나중에 켤 수도 있어요)와 **가입 시 기본 지급**(아래 [기본 지급 아이템](#가입-시-기본-지급-아이템) 참고) 여부를 정해요.

**지형** 카테고리를 골랐을 때는 **"캐릭터 통과 불가(막힘)"** 체크박스도 나와요 — 켜두면 유저가 그 지형 위로 걸어갈 수 없어요(기본 지형 중에서는 "물"이 이렇게 설정돼있어요). 특수 지형(용암, 벽, 낭떠러지 등)을 새로 등록할 때 자유롭게 막을 수 있어요. 다른 카테고리에는 없는 옵션이에요.

이미지 등록 방식이 카테고리마다 달라요.

- **아바타(데코 제외)**: 768×1024, 정면·측면·후면 3열×4행 프레임시트(캐릭터 기본 시트와 같은 형식)를 업로드해요. **업로드를 안 하면** itemKey를 그대로 써서 `/character/{파츠}/{itemKey}.png` 경로의 파일을 찾아요 — 그 경로에 파일이 미리 배포돼있는 경우에만 정상적으로 보여요(가입 시 기본 지급되는 기본 파츠들이 이 방식이에요). **한벌옷**도 이 방식 그대로예요(상의+하의 자리를 합쳐서 대체하는 것뿐, 시트 형식은 같아요).
- **지형**: 이미지를 1장 업로드하면 그게 상점 아이콘이자 **실제로 맵에 그려지는 타일 그림**으로 그대로 쓰여요.
- **맵 아이템**: 레이어 이미지를 1~6 순서로 정확히 6장 골라서 한 번에 업로드해요. 실제로 맵에 놓였을 때처럼 겹친 미리보기 아이콘이 서버에서 자동으로 합성돼서 만들어져요. itemKey는 직접 못 정하고 등록하면서 자동으로 지정돼요(코드에 내장된 레거시 카탈로그와 안 겹치게 하려고요).
- **맵 배경**: 이미지를 1장 업로드해요. 방 편집기의 "배경" 팔레트에서 이 그림을 고를 수 있게 돼요.
- **기능 아이템 / 소모품**: 아이콘 이미지를 1장(선택) 업로드해요. "맵에 심는 작물로 만들기"를 켜지 않았다면 아직 상점에 진열/판매하는 용도로만 쓰이고, 실제 기능은 서버 코드가 별도로 구현해야 해요.

### 데코 아이템 등록하기

데코는 몸 앞이나 뒤에 겹쳐 붙는 장식이라 다른 아바타 파츠보다 세로로 100px씩 더 여유 공간이 필요해요 — 그래서 시트 크기가 **768×1424**(기본 768×1024 시트의 4개 방향 행마다 위쪽에 100px 여유를 끼워넣은 크기)로 달라요. 폼에 있는 **가이드 이미지** 링크(`/character/deco-guide.png`)를 열어보면 어디에 여유 공간이 들어가는지 정확히 표시된 템플릿을 볼 수 있어요 — 그 위에 그려서 올리면 돼요.

등록할 때 **"몸 뒤 레이어" / "몸 앞 레이어"** 중 하나를 꼭 골라야 해요.

- **몸 뒤 레이어**: 캐릭터 뒤에 깔리는 장식(등에 메는 것 등).
- **몸 앞 레이어**: 캐릭터 앞을 가리는 장식.

캐릭터를 뒤에서 보는 각도(등 돌리고 걷는 모습)일 때는 앞/뒤가 화면에서 자동으로 뒤바뀌어서, 항상 실제 위치 관계에 맞게 자연스럽게 보여요 — 등록할 때는 "정면에서 봤을 때 몸 앞/뒤" 기준으로만 고르면 돼요.

### 작물 등록하기

**기능 아이템** 카테고리에서 **"맵에 심는 작물로 만들기"**를 켜면 아래 항목이 추가로 나와요.

| 항목 | 설명 |
|---|---|
| 성장 시간(초) | 심은 시점부터 이 시간이 지나야 수확할 수 있어요 |
| 최소/최대 보상 | 수확 시 지급할 재화 범위 — 그 사이에서 랜덤으로 지급돼요 |

작물도 맵 아이템처럼 **레이어 이미지 6장**을 업로드해요 — 다만 6장이 그냥 겹쳐 쌓이는 게 아니라 **성장 단계**로 쓰여요(심었을 때부터 다 자랄 때까지 단계적으로 더 많은 레이어가 보이는 방식). 유저 쪽에서 실제로 심고 수확하는 방법은 [프로필과 내 방 꾸미기](../04-프로필과-내방.md#작물-키우기-농사) 문서를 참고하세요.

### 바닥에 까는 아이템(behindAvatar)

맵 아이템 / 작물 등록 폼에는 **"바닥에 까는 아이템(캐릭터보다 항상 뒤에 표시)"** 체크박스도 있어요. 러그·카펫처럼 캐릭터가 그 위로 걸어다녀야 하는 장식에 체크해두면, 보통의 위치 기반 앞뒤 판정과 무관하게 **항상 캐릭터보다 아래(뒤)에 그려져요** — 안 켜두면 위치에 따라 캐릭터가 아이템 뒤로 가려질 수도 있어요.

## 오브젝트 스토리지가 없으면?

이미지 업로드 버튼은 **오브젝트 스토리지**(S3 호환)가 설정된 서버에서만 나타나요. 설정 안 돼 있으면:

- 아바타(데코 포함) / 지형 / 맵 배경 / 일반 기능 아이템 / 소모품은 업로드 버튼 대신 URL을 직접 입력하는 칸만 남아요(이미 다른 곳에 올려둔 이미지 URL을 붙여넣는 식으로는 여전히 등록 가능).
- **맵 아이템과 작물은 레이어 업로드 외에 다른 등록 방법이 없어서, 오브젝트 스토리지 없이는 아예 등록할 수 없어요.**

오브젝트 스토리지 설정 방법은 배포 환경의 `.env`(또는 `docker-compose.yml`의 `S3_*`/`NUXT_S3_*` 값)를 참고하세요 — MinIO 자체 호스팅, Cloudflare R2, AWS S3 등 S3 호환 스토리지라면 뭐든 연결할 수 있어요.

## 수정 · 삭제

목록에서 연필 아이콘을 누르면 인라인으로 수정할 수 있어요. 이름/설명/가격/판매 여부/가입 시 기본 지급 여부는 언제든 바꿀 수 있지만, **카테고리와 itemKey는 등록 후 못 바꿔요** — 이미 유저 인벤토리·캐릭터 장착 상태·저장된 맵에 그 값으로 참조가 걸려있어서, 바꾸면 기존 보유자/배치가 깨져요. 다른 카테고리/키로 옮기고 싶으면 새로 등록하고 기존 건 삭제하세요.

- 맵 아이템/작물의 레이어는 6장을 통째로 새로 올렸을 때만 교체돼요(1~5장만 바꾸는 부분 교체는 지원 안 해요).
- 코드에 내장된 예전 카탈로그(`useItemCatalog.ts`)와 연결된 "레거시" 맵 아이템은 레이어를 아예 못 바꿔요 — 그 자리를 가로채면 코드에 내장된 그림과 충돌하기 때문이에요. 그림을 바꾸고 싶으면 삭제하지 말고 새 아이템으로 따로 등록하세요.

삭제는 목록에서 바로 가능해요(하드 삭제, 복구 불가). 이미 유저 인벤토리에 있거나 맵에 배치된 아이템을 지워도 그 참조 자체는 그대로 남아서 계속 렌더링돼요 — 상점 진열에서만 사라져요. 아예 그림까지 없애고 싶다면 삭제 대신 "판매중" 체크를 끄는 걸 권장해요.

## 가입 시 기본 지급 아이템

**가입 시 기본 지급**을 켜서 저장하면, 그 이후 새로 가입하는 유저에게 자동으로 인벤토리에 지급돼요(가격이 있어도 무료로 받아요). 서버에 원래 있던(상점 도입 전부터 전원이 쓰던) 기본 아바타 파츠·기본 지형 5종이 이 방식으로 등록돼있어요.

**이미 가입한 기존 유저**에게도 소급 지급하려면, 서버에서 시드 스크립트를 한 번 더 돌려야 해요.

```bash
npm run db:seed-shop-items
```

이미 등록된 category/itemKey 조합이나 이미 가진 아이템은 건드리지 않고 건너뛰니, 몇 번을 다시 돌려도 안전해요. 도커로 배포한 경우 DB 컨테이너에 직접 접속해서 실행해야 하는데, 자세한 방법은 배포 문서를 참고하세요.

## 맵 편집기 팔레트와의 연동

지형/맵 아이템/맵 배경/작물을 등록해두면 [채널 관리](./03-채널-관리.md)의 맵 편집(관리자용, 마을/채널 맵)에서는 등록된 전체가 팔레트에 나와요. 반면 유저 개인 방([프로필과 내 방 꾸미기](../04-프로필과-내방.md#내-방-꾸미기)) 편집기는 그 유저가 **실제로 보유한 만큼만** 팔레트에 나와요 — 그래서 특수 지형이나 맵 아이템(작물 포함)을 유료로 팔면, 산 사람만 자기 방에 놓을 수 있게 돼요.
